## 📝 使用说明

### 本地开发

1. **安装依赖**
   ```bash
   cd agent-edu-platform
   pnpm install
   ```

2. **启动前端**
   ```bash
   pnpm run dev
   # 访问 http://localhost:5173
   ```

3. **启动后端**
   ```bash
   cd server
   node index.js
   # API运行在 http://localhost:3001
   ```

### 生产部署

1. **前端部署**
   - 已构建完成,点击"发布"按钮即可部署到公网
   - 或手动部署到 Vercel/Netlify

2. **后端部署**
   - 推荐使用 Railway/Render/Heroku
   - 配置环境变量 (DATABASE_URL, JWT_SECRET等)
   - 运行数据库迁移

### 数据库配置

1. **创建PostgreSQL数据库**
   ```sql
   CREATE DATABASE agent_edu_db;
   ```

2. **配置连接字符串**
   ```env
   DATABASE_URL="postgresql://user:password@host:5432/agent_edu_db"
   ```

3. **运行迁移**
   ```bash
   cd server
   npx prisma migrate deploy
   npx prisma generate
   ```

## 🔧 配置说明

### 环境变量

**后端 (server/.env):**

```env
# 服务器配置
PORT=3001
NODE_ENV=production

# 数据库
DATABASE_URL="postgresql://..."

# JWT密钥
JWT_SECRET=your-super-secret-key

# Dify Agent API
DIFY_API_KEY=your-dify-api-key
DIFY_API_URL=https://api.dify.ai/v1

# CORS
CORS_ORIGIN=https://your-frontend-domain.com
```

**基础URL**: `http://localhost:3001/api`

## ⚠️ 注意事项

### 当前限制

1. **数据库** - 当前使用模拟数据,需配置PostgreSQL
2. **文件存储** - 本地存储,生产环境建议使用云存储(S3/OSS)
3. **邮件服务** - 验证码发送功能为模拟,需集成SendGrid
4. **Agent API** - 当前为模拟响应,需配置Dify API密钥

### 安全建议

1. **更换JWT密钥** - 使用强随机密钥
2. **启用HTTPS** - 生产环境必须使用HTTPS
3. **限制CORS** - 仅允许特定域名访问
4. **文件验证** - 加强文件类型和大小验证
5. **SQL注入防护** - 使用Prisma ORM已提供保护

### 性能优化

1. **代码分割** - 使用React.lazy进行路由懒加载
2. **图片优化** - 压缩图片,使用WebP格式
3. **CDN加速** - 静态资源使用CDN
4. **数据库索引** - 为常查询字段添加索引
5. **缓存策略** - 使用Redis缓存热点数据
